Nocturne을 맥 앱으로. 메뉴 막대 카운트다운, 떠 있는 창, 바탕화면 위젯이 함께 들어 있어요.
Nocturne as a Mac app, with a menu bar countdown, a floating window and desktop widgets.

**설치**
1. `Nocturne.dmg`를 열고 Nocturne을 응용 프로그램 폴더로 끌어다 놓으세요.
2. 처음 열 때 "Apple에서 확인할 수 없음"이 뜨면: 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 **그래도 열기**. (Apple 개발자 서명이 없는 앱이라 한 번만 필요해요.)

**Install**
1. Open `Nocturne.dmg` and drag Nocturne into Applications.
2. If macOS says it can't verify the app the first time: System Settings → Privacy & Security → **Open Anyway** (once; the app isn't signed with an Apple Developer ID).

**들어 있는 것 / What's inside**
- 메뉴 막대: 타는 동안 남은 시간이 초 단위로, 기다리는 동안 다음 출발 시각이 떠요. / Menu bar: the time left on board, or the next departure.
- 떠 있는 창 (⇧⌘F): 다른 앱 위에 늘 떠 있는 작은 카드. 두 번 누르면 Nocturne이 열려요. / Floating window (⇧⌘F): stays above other apps; double-click to open Nocturne.
- 위젯: 바탕화면에서 우클릭 → 위젯 편집 → Nocturne. 작게·중간·크게. / Widgets: right-click the desktop → Edit Widgets → Nocturne.
- 창을 닫아도 메뉴 막대에 남아 있어요. 끝내려면 메뉴 막대 → Nocturne 종료. / Closing the window keeps it in the menu bar; quit from there.
